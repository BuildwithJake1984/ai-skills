# Features blueprint cards — three-up pattern

Screenshot-only reference (no public source URL). Three-column feature cards with a technical/blueprint aesthetic on a dark grid field.

## Pattern notes
- Section header: diamond mark + “FEATURES” label and a horizontal dotted rule.
- Three equal vertical cards; first card is a bright orange accent, the other two cream/off-white.
- Each card: bold title top-left, zero-padded serial (001–003) top-right, large geometric line illustration on a fine dotted grid with corner brackets, then a notched footer strip with one-line description and a 4-dot grip on the right.
- Illustrations stay abstract (concentric +/− circles, radiating triangle, hatched Venn) — swap geometry to match product meaning.
- Use for product feature or capability rows when you want a technical, Swiss-minimal card language; adapt colors/tokens and rewrite copy — do not ship the sample support-agent wording wholesale.

## When to use
- Designing or reviewing a 3-up features / capabilities section with strong graphic identity.
- Prefer your project's approved component library; this is visual pattern inspiration only.
