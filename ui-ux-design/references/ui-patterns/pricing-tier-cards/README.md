# Pricing tier cards — three-plan pattern

Screenshot-only reference (no public source URL). Three-column SaaS pricing with monthly/annual billing toggle.

## Pattern notes
- Headline left (“Simple Pricing, No Surprises”); pill billing toggle right (Monthly | Annual).
- Three cards: Starter ($0), Professional ($19, Most Popular), Business ($49).
- Starter: light gray shell, soft CTA.
- Professional: blue→pink gradient header, red “Most Popular” badge, high-contrast black CTA.
- Business: dark shell, longer feature list (roles, API).
- Shared: large rounded corners, nested price panel, checkmark lists, “Start Free Trial” CTAs.
- Use for product pricing or plan-comparison UIs; adapt copy/tokens — do not copy placeholder feature copy wholesale.

## When to use
- Designing or reviewing a 3-tier pricing section.
- Prefer your project's approved component library; this is visual pattern inspiration only.
